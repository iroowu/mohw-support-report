# 衛福部報備支援系統操作要點

系統全名：醫事人員及醫事機構線上申辦系統，報備支援在「報備支援申辦專區」。
登入頁：https://euservice.mohw.gov.tw/Apply_001011/Login1

以下是實際操作過的做法。系統日後若改版，以現場頁面為準；本檔寫的元件 id 對不上時，先讀頁面結構再動手，不要硬套。

## 一、登入與交接

1. 用瀏覽器工具開登入頁，認證方式由使用者自己選（常見是「健保卡登入(無卡)」）。
2. 身分證字號、健保卡卡號、密碼、多因子驗證碼，全部由使用者本人在自己的瀏覽器分頁輸入。AI 不讀這些欄位、不打字、不截圖存檔。
3. 登入完成後，畫面右上會出現「（使用者姓名） 您好」，並進到報備支援申辦專區。
4. **登入交接**：AI 操作的分頁常常與使用者自己登入的分頁不在同一個分頁群組，AI 看不到使用者那頁。做法是：
   - 請使用者在自己登入成功的那一頁，複製網址列整串網址（裡面帶有 `?result=...` 的登入回呼參數）貼給 AI。
   - AI 在自己的分頁打開這串網址，就會是登入狀態。
   - 這串網址等同一次性的登入憑證，AI 用完不保存、不寫進任何檔案或紀錄。
5. 登入有時效，閒置太久會被登出。被登出時請使用者重新登入、再交接一次，不要嘗試自動登入。

## 二、建立一家診所的申請（登錄 → 單筆申請）

每一家被支援機構各做一次以下步驟。

### 1. 選被支援機構

- 先選縣市、再選鄉鎮市區。這兩個是下拉選單，直接用頁面上的 jQuery 設值並觸發變更事件最穩：
  `$('#縣市下拉的id').val('值').trigger('change')`，鄉鎮清單會隨縣市重新載入，等它載入完再設鄉鎮。
  元件 id 以現場頁面為準，先用讀頁面結構的工具找出來。
- 機構關鍵字欄是 select2 搜尋框：先點一下框、再打字、按 Enter 選定第一筆。
  打**機構代碼**最準（10 碼數字，只會命中一筆）。
- 選定後用 JavaScript 讀隱藏欄位 `ITEM_BAS_SEQ_forSelect2` 的值，確認真的有選到。
- 按「新增」。跳出的機構資料要核對機構代碼與設定檔一致。
  正式名稱與使用者的慣稱不同是常見的（例：慣稱用地名，系統登記的是公司或診所全名），**以代碼為準**。
  若代碼查出的縣市或鄉鎮明顯不合理，停下來問使用者。

### 2. 填明細

- 支援目的：只勾「**報備為一般支援**」，其他不勾（除非使用者另外交代）。
- 附件、備註：留空。

### 3. 設支援時間（用「選擇」模式）

支援時間有幾種輸入模式，用「**選擇**」：先設一段起訖時間，再在月曆上勾適用的日期。

- 起訖時間是 30 分鐘一格的下拉選單，id 是 `PRD_SDATE3_HM`（開始）與 `PRD_EDATE3_HM`（結束），值是四碼時間，例如 `1400`、`2030`。
  一律用 id 設值，設完再讀回確認。
  注意：同頁另有「間斷」模式的一列，外觀相似，用文字搜尋元件的工具常常會抓錯成那一列，所以不要靠搜尋文字找下拉，要用 id。
- 日期勾選框的 id 是 `date-YYYY/MM/DD`，例如 `date-2026/11/05`。月曆預設顯示當月，要報下個月時先按「下個月」或用右上的月份選單切過去。
- 勾好日期後按「**新增時間**」，下方表格會逐筆出現「開始時間／結束時間」。逐筆核對。
- **每按一次「新增時間」，頁面會重新載入**：月曆跳回當月、所有勾選清空。下一段時間要重新切月、重新設起訖、重新勾日期。
- 同一家診所有兩種以上時段（例如午段與晚段分開報，或某幾天是早班某幾天是晚班）：**先改好起訖、再勾那一批日期、再按新增時間**，一段一段來，不可以沿用上一段的起訖。
- 表格上有「超過40%」欄，若有被標記，截圖告訴使用者。

### 4. 儲存

逐筆核對表格與確認過的清單一致後，按「**儲存**」，回到單筆申請頁做下一家。

## 三、進預覽頁，停住

1. 全部診所都儲存後，在單筆申請頁按「**請預覽確認內容無誤於下一步驟進行送審**」。
2. 會跳出「確定要送此筆支援資料？」的確認框。這一步**只是進入預覽頁**，還沒有送審，可以按確定。
3. 預覽頁（網址含 `ApplyDetailAfterSave`）會寫著「尚未送出」。真正的「**送審**」鈕在預覽頁最底部。
4. AI 停在這裡，把預覽頁內容逐家、逐日、逐段與確認過的清單核對一次，回報核對結果，並明講：
   「目前尚未送出。請您本人檢查預覽頁，確認無誤後自己按最下方的『送審』。」
5. AI 絕不按送審。
6. 使用者送審成功後，頁面會出現「報備支援申請資料送審完成」。頁面同時提醒：有錯可以「申請撤案」後重報。

## 四、送審後

- 按「**列印同案申請書**」下載 PDF，檔名形如 `B1C101M01醫事人員報備支援申請書-案件編號.pdf`。
- 用 `scripts/verify_filing.py` 驗收（見 SKILL.md）。

## 五、案件查詢、變更與撤案

- 案件查詢的「支援日期」欄要用**真的鍵盤輸入**。用 JavaScript 直接設值，系統會當成空白，還會跳「案件編號、支援日期請至少須輸入一項」。
- 查到「查無資料」時，先用一筆確定存在的案件做對照組，確認查詢方法本身沒問題，才下「沒有這筆案件」的結論。
- 撤掉的段可以用申請類別「註銷」查到。舊的申請書 PDF 不會因為撤案而改變，所以驗收時要用 `--exclude` 告訴程式哪些段已經撤掉。
- 已送出的案件有錯：先告訴使用者，經同意後用「變更」或「申請撤案」處理，不直接改。

## 六、瀏覽器操作的小技巧

- 用元件參考（ref）點按鈕常常沒反應，這時改用畫面座標點。系統的確認框「確定」鈕通常在畫面正中偏右下。
- 每做完一步都讀回頁面確認狀態，不要連續盲按。
- 同一個操作連續失敗兩次就停下來，換方法或回報使用者，不做第三次原樣重試。
