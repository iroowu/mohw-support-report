# 報備支援小幫手（mohw-support-report）

給 Claude 用的技能包，幫在多家診所支援看診的醫師，每個月把上診班表報備到衛福部「醫事人員及醫事機構線上申辦系統」。

## 它能幫你做什麼

每個月報備支援，原本要自己做這些事：查每家診所的機構代碼、翻行事曆把每一天抄下來、在系統裡一家一家選機構、一天一天勾日期、分段的時間一段一段設、最後再對一次有沒有打錯。

裝好之後，這些都交給 AI：

1. 第一次使用時，用你說的診所名稱查出機構代碼，記在你自己電腦上。
2. 每個月從你的 Google 上診行事曆（或你貼給它的班表）整理出申報清單：每家診所哪幾天、幾點到幾點，請假與取消的日期另外列出不報。
3. 你確認清單後，它在報備系統裡逐家填寫：選機構、勾支援目的、設時段、勾日期、存檔。
4. 做到送審前最後一頁（預覽頁）就停下來，告訴你「尚未送出」。
5. 你送審之後，它可以幫你下載申請書，用程式逐筆核對有沒有漏報、多報、時間打錯，以及不同診所的時段有沒有重疊。

## 你要自己做的三件事

1. **登入報備系統**。身分證字號、健保卡卡號、密碼與驗證碼都由你自己輸入，AI 不經手。
2. **提供班表**。連上 Google 日曆讓它自己讀，或直接把班表貼給它。
3. **告訴它診所名稱**。只有第一次要講，之後它會記得。

最後的「送審」鈕也由你本人按。

## 你需要準備什麼

| 需要 | 說明 |
|---|---|
| 付費版 Claude（Pro 以上） | 免費版不能使用技能包，也不能操作瀏覽器。 |
| Claude 桌面版或 Claude Code（建議） | 在你的電腦上執行，設定會一直保存。也可以用 claude.ai 網頁版，但每次新對話要把設定貼回去（見常見問題）。 |
| Chrome 瀏覽器與 Claude in Chrome 擴充功能 | 讓 AI 操作你已登入的報備系統分頁。沒有的話，AI 只能幫你整理清單，系統要自己填。 |
| Google 日曆連接器（選配） | 在 Claude 的設定裡連上 Google 日曆，AI 就能自己讀班表。不連也可以，每月把班表貼給它。 |
| Python 3.8 以上 | Mac 通常已內建。Claude 會在第一次使用時自動檢查。 |

## 安裝

**claude.ai 或 Claude 桌面版**：下載本倉庫 `dist` 資料夾裡的 `mohw-support-report.skill`，到 claude.ai 左側「Customize」裡的 Skills，按「Add」再選「Upload skill」，把檔案傳上去。上傳後約一兩分鐘完成安全檢查就能用。

**Claude Code**：把整個 `mohw-support-report` 資料夾放到你電腦的 `~/.claude/skills/` 底下（資料夾名稱不要改）。

## 第一次使用

對 Claude 說：「幫我報備支援」。

它發現你還沒有設定，會一步一步問你：

1. 你在哪幾家診所支援、各在哪個縣市鄉鎮、行事曆上怎麼稱呼它們。
2. 它去查機構代碼，查到好幾家同名的會列出來讓你挑。
3. 你的上診班表在哪一本 Google 日曆（或你要每月貼班表）。
4. 有沒有哪家診所要把午段與晚段分開報、或某種班固定報某個時段。
5. 申請書要存在哪個資料夾（可以不設）。

問完它會把設定存在你自己電腦的 `~/.mohw-support-report/config.json`，給你看一遍。之後就不用再問。

## 每個月使用

1. 月底前對 Claude 說：「幫我報備下個月」。
2. 它給你一張申報清單，逐家逐日看過。要改的直接跟它說，例如「11 月 17 日那天不報」。
3. 你說清單沒問題後，它打開報備系統登入頁，你自己登入。
4. 它逐家填寫，最後停在預覽頁。
5. 你檢查預覽頁，沒問題就自己按「送審」。
6. 告訴它送審完成，它幫你下載申請書、跑核對程式、存檔。

## 隱私與責任

- **AI 不經手任何登入資料**。身分證字號、健保卡卡號、密碼、驗證碼都由你本人輸入，技能包不會讀取、不會記錄。
- **資料只送到衛福部系統**。技能包沒有自己的伺服器，不會把你的班表、診所資料或申請內容傳到別的地方。你的設定只存在你自己的電腦上。第一次查機構代碼時，會從健保署與衛福部下載公開的醫事機構清單到你的電腦上比對；若用「即時查詢」，會把診所名稱關鍵字送到健保署的公開查詢服務。
- **申報內容的正確性由醫師本人確認**。AI 會盡力核對，但送審前請你親自檢查預覽頁。送審鈕一定是你本人按。
- 你使用的 AI 服務（Claude）會看到對話中出現的班表與診所名稱，這部分依該服務的隱私政策處理。

## 常見問題

**系統裡的診所名稱跟我平常叫的不一樣，會不會報錯？**
不會。報備系統以 10 碼機構代碼辨識診所，名稱不同是常見的（例如你叫它地名，系統登記的是全名）。AI 會以代碼為準，並在你第一次設定時把正式名稱給你確認。

**我某天臨時換到另一家支援，要怎麼辦？**
跟 AI 說哪一天從哪家換到哪家。它會補報新診所，也會提醒你原本那家那天如果已經報過，要申請撤案，避免同一時段報了兩家。

**送審後發現報錯了？**
系統可以「申請撤案」後重報，或用「變更」修改。AI 會先跟你確認，不會自己動已送出的案件。

**我用 claude.ai 網頁版，為什麼每次都要重新設定？**
網頁版每次新對話都是全新的環境，存在電腦上的設定不會留下來。第一次設定完，AI 會把設定內容整份給你，請你存起來；下次開工時貼給它就好。用桌面版或 Claude Code 沒有這個問題。

**我沒有用 Google 日曆。**
沒關係，每個月把班表貼給 AI，文字或截圖都可以。截圖的話它會逐筆念給你確認。

**查不到我的診所代碼。**
診所改過名、或平常叫的是品牌名時，公開資料裡可能還是舊名。這時 AI 會問你診所在哪條路，改用地址查。新開業的診所公開資料可能還沒更新，登入報備系統後 AI 會再用系統內的搜尋找一次；還是找不到，請向診所行政人員要 10 碼機構代碼。
